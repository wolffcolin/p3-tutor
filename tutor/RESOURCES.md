# Multi-agent orchestration Resources

## Knowledge

- [Anthropic Engineering: How we built our multi-agent research system](https://www.anthropic.com/engineering/multi-agent-research-system)
  Primary source on the orchestrator-worker pattern: how a lead agent decomposes work, what each subagent must be told, effort scaling, token cost, and where multi-agent is a poor fit (most coding). Use for: any lesson on dividing a task among agents.
- [Claude Code docs: Subagents](https://code.claude.com/docs/en/sub-agents)
  Official reference for subagents: own context window, custom system prompt, tools, returns only a summary, parallel limits, nesting depth. Use for: how to build and delegate to subagents in Claude Code.
