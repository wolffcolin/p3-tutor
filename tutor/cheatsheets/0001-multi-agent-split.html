Splitting a task across agents

From lesson 0001.

Roles

Lead: plan, spawn, synthesize. Workers: one piece each, own context, return a summary.

Four-part brief

  1. Objective
  2. Output format
  3. Tools and sources
  4. Task boundary

Split it only if

  • The pieces are independent (parallel).
  • The task exceeds one context window.
  • It needs many tools.
  • The value covers the cost (about 15x chat tokens for a team, per Anthropic).

Keep sequential

Anything the workers share (a wrapper, a schema, a log format): the lead does it first. Workers cannot talk to each other, and the lead waits for the whole batch.

Source
