# A language model turns the text it is given into more text

Riley can explain that a language model takes text in and produces text out, one token at a time, by predicting what is likely to come next from patterns learned in training.
Riley also sees that the model knows only what it learned in training plus what is in the text it is given, which is the floor for everything that follows: tools, context and memory all come down to what the model is given as input.

**Evidence:** Explained, in their own words, why a chatbot can state an outdated fact with confidence: its knowledge stops where its training data stops, and it produces plausible text whether or not that text is true.

**Implications:** Tokens came up only in passing.
What a token is, and why tokens matter for the size of the context and for cost, has not been taught yet.
