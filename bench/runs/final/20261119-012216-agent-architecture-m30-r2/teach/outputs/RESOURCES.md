# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Defines context, the attention budget and context rot, upfront versus just-in-time retrieval, compaction, structured note-taking and sub-agents. Use for: what an agent keeps in context, what it saves outside it, and how it retrieves.
- [Docs: "Context windows" (Claude Platform Docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  Official description of the context window and how it grows with each turn, including cached input and token counting. Use for: how history accumulates and why that affects cost.
- [Article: "Building effective agents" (Anthropic)](https://www.anthropic.com/research/building-effective-agents)
  Describes the augmented LLM (retrieval, tools, memory) and advises starting with the simplest solution. Use for: where retrieval and memory sit in an agent design. Note: the page says parts of the tooling landscape have changed since December 2024.
