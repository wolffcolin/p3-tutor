# Open misconceptions: the model runs tools (M4) and remembers across sessions (M3)

On quiz 0001 (s1) the learner has the loop's shape and the idea that the model picks tools from their names and descriptions. They still credit the model with running tools itself (M4, q2 and q4) and with remembering past picks across sessions (M3, q6).
Later lessons on memory and workflows should state plainly that the program runs tools and that the model knows only what is in its current input.

**Evidence:** quiz 0001, submission s1, items q2, q4, q6.
