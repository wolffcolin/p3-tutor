Context and memory in an agent

From lesson 0003.

  • The model sees only the tokens the program sends in each call. The program resends the whole messages list every step, so input grows each step.
  • Input at call n = input at call n-1 + the model's output + the tool result.
  • Billing is per input and output token. More context also means weaker recall (context rot).
  • Too long: clear old tool results first, then compact (summarize and restart).
  • Between sessions nothing persists unless the app saves it. The memory tool is client-side: the model asks, the app runs the file operation.
