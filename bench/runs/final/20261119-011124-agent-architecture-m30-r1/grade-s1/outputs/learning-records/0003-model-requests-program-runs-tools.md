# Open misconception: the model runs tools itself (M4), and memory comes free (M3)

On quiz 0001 (s1) the learner twice described the model as running tools inside one call (q2, q4), and said the model remembers its tool choices across sessions (q6). They do understand the loop's shape and that the model chooses tools from their descriptions (q1, q3).
Next lessons should separate what the model outputs (a tool request) from what the program does (runs it, returns the result, calls again), and show that memory is something the program sends in each call.

**Evidence:** quiz 0001, submission s1, items q2, q4, q6.
