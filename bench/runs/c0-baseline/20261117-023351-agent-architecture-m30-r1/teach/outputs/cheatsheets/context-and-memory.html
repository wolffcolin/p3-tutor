Context and memory in an agent

From lesson 1.

Terms

TermMeaning
ContextEverything the model reads and writes in one call.
Context windowThe limit on the context; it holds system prompt, tool descriptions, messages, tool results and output.
Context rotRecall gets worse as the context grows.
CompactionSummarize the history and continue in a new context.
Notes / memoryInformation saved outside the model and loaded back by a tool.
RetrievalFinding the few relevant chunks and putting only those in context.

Rules of thumb

  • The model keeps nothing between calls: the program re-sends the whole message list, and every call is billed for all of it.
  • Total input tokens = the sum of each call's input, not the size of the last call.
  • Keep the smallest useful context; clear big tool results once used.
  • A bigger window is not memory. Memory between sessions is storage plus a tool to read it.
  • Return short, labelled search results (machine, section, page).
  • Start with the simplest design that works.
