Cheat sheet: context and memory

From lesson 1. Source: Anthropic, Effective context engineering for AI agents.

TermMeaning
TokenThe chunk of text a model reads and writes; what you are charged for.
ContextThe tokens sent to the model for one call.
Context windowThe limit on the context's size.
Context rotRecall gets worse as the context grows.
SessionOne conversation; its context is gone when it ends unless saved.
NotesFacts saved outside the context and loaded back later.
RetrievalFetching only the relevant chunks into the context.

Rules of thumb

  • The model keeps nothing between calls; the program re-sends everything.
  • Cost of a request is about the sum of context sizes over all its calls, plus output.
  • Keep tool results small; clear used ones; compact only for long runs.
  • Save stable facts about people as notes; look up live data and long documents.
  • If an answer is wrong, check first whether the right chunk was retrieved.
