# A language model does not remember earlier conversations on its own

The learner believed a model automatically remembers earlier conversations, so the makerspace assistant would recall what each student said last week. This was corrected: the model only sees what is in the current request, so memory between sessions must be built by the assistant's code (saving and reloading information).
Understanding is not yet confirmed; check it with a retrieval question before building on it.

**Evidence:** the learner's message at the start of the session on 2026-11-16.
**Implications:** the next lesson on context and memory can start from this correction.
