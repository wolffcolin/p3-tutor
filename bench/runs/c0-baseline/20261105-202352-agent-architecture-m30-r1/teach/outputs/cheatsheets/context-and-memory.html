Context and memory in an agent

From lesson 1.

TermMeaning
ContextAll the tokens sent to the model on one call: system prompt, tool definitions, history, tool results; the output counts too.
Context windowThe limit on how much the model can work with in one call.
Context rotRecall and accuracy degrade as the token count grows.
CompactionSummarize a long conversation and start a new window with the summary.
Notes / memoryFacts saved outside the window and loaded into a later context.
RetrievalSearch a large collection and add only the best chunks to the context.

Where does it go?

  • Needed every call: system prompt (keep short).
  • Large and fixed (manuals): searchable store, retrieve chunks.
  • Needed only for this request: keep in context, clear when done.
  • Exact and must persist (training status): database written by the program, loaded at session start.
  • Soft and helpful: short notes file.
