# Open misconception: the model runs the tools itself (M4), and remembers across sessions (M3)

In quiz 0001, submission s1, Riley got the loop (q1) and the stopping condition (q3) right and knows the model picks tools from names and descriptions. Riley also wrote that the model "runs the 3 tools itself" (q2, q4) and "remembers on its own" earlier sessions' tool choices (q6). The program runs the tools, each tool result needs its own model call, and memory has to be saved and supplied by the program.

**Evidence:** quiz 0001, submission s1, items q2, q4 and q6.

**Implications:** Re-teach "model writes a request, program runs it" with a concrete trace and a count of model calls before building on it. The context and memory lesson should start by showing that the model starts each call with only what is in its input. Submission s2 is later, spaced practice and may show whether this has been fixed.
