# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic)](https://www.anthropic.com/research/effective-context-engineering-for-ai-agents)
  Context rot, compaction, note-taking, just-in-time retrieval, sub-agents. Use for: what to keep in context, memory design, multi-agent trade-offs.
- [Docs: "Context windows" (Claude Platform)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  How the window accumulates across turns and what counts toward it. Use for: token counting, cost per call, window sizes.
- [Article: "Contextual Retrieval" (Anthropic)](https://anthropic.com/research/contextual-retrieval)
  Chunking, embeddings, keyword search and chunk labelling for RAG. Use for: finding the right page in long manuals.
