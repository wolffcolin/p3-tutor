Context and memory in an agent

From lesson 1. The model keeps nothing between calls; memory is what your program sends.

Cost rule

Input tokens are paid on every call. A chunk of T tokens that arrives before k more calls costs about T × k. Clear it from the history once it is used.

Keeping a run lean

  • Clear old tool results (lightest).
  • Compact: summarize history into a new window.
  • Sub-agent: clean window, short summary back.

Retrieval steps

Chunk → index (embeddings + BM25) → search → insert top chunks. Prepend the machine and section name to each chunk so it keeps its context.
