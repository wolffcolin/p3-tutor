Context and memory in an agent

From lesson 1.

Rules

  • Window = system prompt + tool definitions + history + tool results + output, per call.
  • The model keeps nothing between calls; the program resends the history.
  • Input billed = sum of every step's full input, so cost grows with steps × history.
  • Keep context small and high-signal (context rot). Clear old tool results; compact if still too long.
  • Across sessions: records written by code for exact facts, notes for loose ones; load only what the request needs.
