Context and memory: one-page reference

From lesson 1. The model sees only its context window; everything else is text your program puts there.

Cost rule

Total input tokens = the sum over every model call of the whole context at that call. Call n input = call n-1 input + the model's request + the tool result.

Keeping the window small

1. Make tools return less. 2. Clear old tool results. 3. Compact long chats (lossy; save must-keep facts to notes). 4. Hand sub-tasks to a sub-agent with a clean window.

Notes

Memory tool is client-side: the model requests view, create, str_replace, insert, delete or rename under /memories; your code runs them and must reject paths outside it. Notes go stale: use tools for live facts.

Retrieval

Chunk, embed, store, retrieve. Add keyword search (BM25) for exact strings such as error codes. Prepend context to chunks that lose it. Under about 200,000 tokens (about 500 pages) consider a cached prompt instead.
