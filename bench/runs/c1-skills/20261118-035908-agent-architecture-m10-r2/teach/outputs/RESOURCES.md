# Agent architecture Resources

## Knowledge

- [Effective context engineering for AI agents (Anthropic)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context as a finite attention budget, context rot, just-in-time retrieval, compaction, note-taking. Use for: what to keep in context and why.
- [Context windows (Claude Platform docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, how turns accumulate, compaction and context editing. Use for: token accounting and cost.
- [Memory tool (Claude Platform docs)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  Client-side file memory across sessions, the multisession pattern. Use for: designing what the assistant saves between visits.
- [Contextual Retrieval (Anthropic)](https://anthropic.com/research/contextual-retrieval)
  Chunking and indexing manuals so searches find the right chunk. Use for: how the assistant finds a page in a long manual.
