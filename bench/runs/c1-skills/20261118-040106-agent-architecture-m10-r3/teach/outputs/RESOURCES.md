# Agent architecture Resources

## Knowledge

- [Anthropic Engineering: Effective context engineering for AI agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on context as a finite resource, context rot, compaction, tool-result clearing, notes and just-in-time retrieval. Use for: anything about what goes in context and what is saved outside it.
- [arXiv 2603.07670: survey of agent memory](https://arxiv.org/html/2603.07670)
  Survey (2022 to early 2026) organizing agent memory by form, function and dynamics. Use for: going deeper than short-term vs. long-term.
- [Elastic Search Labs: agentic memory management](https://www.elastic.co/search-labs/blog/agentic-memory-management-elasticsearch)
  Vendor-written practical view of storing and retrieving agent memory. Use for: implementation ideas; treat as secondary.
