Rules of thumb

  • Total input cost = sum of every call's input, not the final size.
  • Trim: filter in the tool, clear old results, then compact.
  • Under about 200,000 tokens of manuals? Try putting them all in the prompt with caching first.
  • Retrieval: chunk, index with embeddings and BM25, return the top few chunks.
