# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context, context rot, just-in-time vs pre-inference retrieval, compaction, note-taking, sub-agents. Use for: anything on context and memory design, and later multi-agent questions.
- [Article: "Managing context on the Claude Developer Platform" (Anthropic)](https://claude.com/blog/context-management)
  Context editing and the memory tool, with Anthropic's internal results. Use for: concrete mechanisms for clearing tool results and file-based memory.
- [Article: "LLM Powered Autonomous Agents" by Lilian Weng](https://lilianweng.github.io/posts/2023-06-23-agent)
  Overview of agents with planning, memory and tool use; vector-store retrieval. Use for: the wider picture of agent memory (2023, so check newer sources for tooling).
