Context and memory: cheat sheet

From lesson 1. The model keeps nothing between calls; your program builds the context each time.

Cost

Request cost = input tokens summed over every call. Anything in the context is resent on each later call: extra cost = tokens x number of later calls.

Where information lives

LayerLastsTools
Context (this call)One callKeep small; small tool results
Message listOne sessionClear stale tool results; compact near the limit
StorageAcross sessionsDatabase row for exact facts (training status); short note file for soft context
Searchable storePermanentChunked manuals; pre-inference search, or a search_manual tool (just-in-time)

Rules of thumb

  • Aim for the smallest set of high-signal tokens; accuracy falls as context grows (context rot).
  • Return few, well-aimed chunks, not many.
  • Never gate a permission on a note the model wrote; check a record.
