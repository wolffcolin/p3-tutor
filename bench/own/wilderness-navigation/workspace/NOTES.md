# Notes

## Already know
- Recognize contour lines, elevation labels, map scale, and cardinal directions.
- Understand that closely spaced contours indicate steeper terrain.
- Can identify a trail junction or prominent ridge on a topographic map.

## Still learning
- Transferring a bearing from a map to a compass and accounting for declination.
- Distinguishing true or grid north from magnetic north.
- Following a bearing without drifting and confirming position using more than one clue.
- Selecting handrails, checkpoints, and catching features for a cautious off-trail route.

## Common sticking points
Tends to mix up the direction of a return bearing and is not yet consistent about checking the map's north reference before using a compass.
