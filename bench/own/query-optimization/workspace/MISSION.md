# Mission

## Why
I can write SQL, but I want to understand why the same logical query can run quickly or slowly depending on its physical plan.

## What success looks like
I can explain filtering and index tradeoffs, compare common join strategies using concrete row counts, and read a simple plan well enough to identify likely bottlenecks.

## Constraints
I learn best from small tables, explicit intermediate results, short code or SQL examples, and practice that builds from guided to independent.

## Out of scope
Database-engine implementation internals and vendor-specific optimizer flags are not required yet.
